# Agegmemnon

Marketing homepage for Agegmemnon — offline patent intelligence for USPTO examination, prior art, classification, and public-safe inquiry.

## Develop

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize later

- Logo: `src/components/Logo.tsx`
- Copy & sections: `src/components/*`
- Stock videos/images: URLs in `Hero.tsx`, `ProductSections.tsx`, `OfferingsCarousel.tsx`, `Impact.tsx`
